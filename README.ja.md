# Prior-Scout

**既存の成果を探す。根拠を確かめてから伝える。**

Prior-Scout は、AI エージェントが似たソフトウェア、ライブラリ、ツール、Agent Skills、
研究を探すための小さな Agent Skill です。一次資料を読み、重要な機能を確認し、
共通点、違い、まだ分からない点を簡潔にまとめます。

エージェントが持つ検索・資料読み取りツールを使う指示集であり、独立した検索エンジンや
調査サービスではありません。

## こんなときに

新機能を作る前に既存のオープンソースツールを調べたいとき、特定の作業に使える Skill を
探したいとき、原著論文をもとに研究手法を比較したいときに使えます。
日常的な修正や、方針が決まっている実装で改めて検索を始める必要はありません。

## インストール

Node.js 22.20 以降と npm が必要です。利用するプロジェクトのディレクトリで、
Codex 向けのコマンドを実行します。

```sh
npx skills@1.7.4 add orange-clockwork/prior-scout --skill prior-scout -a codex --copy -y
```

`main` の Skill がプロジェクトの `.agents/skills/prior-scout/` にコピーされます。
実行前に既存のインストールがないか確認してください。プロジェクトをまたいで使う場合は
`--global` を追加します。

v1.0.0 に固定する場合は、`orange-clockwork/prior-scout` を
`https://github.com/orange-clockwork/prior-scout/tree/v1.0.0` に置き換えます。
インストールされたファイルを確認してください。読み込みには新しいエージェントのセッションが
必要になる場合があります。

## 使い方

Codex では Skill 名を明示して呼び出せます。

> $prior-scout を使って、Markdown のリンクチェッカーを作る前に既存のオープンソースツールを
> 調べてください。各ツールのドキュメントを読み、ローカルファイルや見出しへのリンクに対応しているかを比較し、
> その後、自作ツールの実装計画をまとめてください。

自動で呼び出されるかどうかは、実行環境とモデルによります。

## 動作の流れ

Prior-Scout は関連する候補を探し、公式ドキュメント、リポジトリ、論文などの一次資料を読み、
資料で裏付けられる機能を出典リンク付きで比較します。公開済みの機能、予定されている機能、
不明点は分けて示します。検索結果やスニペットは手掛かりであり、一次資料による確認には含めません。

既定の上限は検索クエリ6件と、異なる外部文書8件です。これは指示上の制限であり、
コードによって強制されるものではありません。

採用するかどうかは利用者が決めます。候補のインストールは行いません。
後続の作業も依頼されている場合、エージェントは元の依頼の範囲で作業を続けます。

## 制約

実行環境に検索・資料読み取りツールが必要です。調査範囲はツールとアクセス可能な資料に左右され、
網羅的な検索は保証できません。より近い候補を見落とすこともあります。
ドキュメントを読むことと、ツールの実際の動作を確認することは別です。

テスト済みの構成は、macOS 26.4.1 arm64 上の Codex CLI 0.164.0 と gpt-6.1-sol/high です。
他の実行環境でのネイティブ対応は未検証です。[互換性の記録](docs/compatibility.md)を参照してください。
