# Prior-Scout

**既存の成果を探す。根拠を確かめてから伝える。**

既存ソフトウェア、ライブラリ、Agent Skills、研究を調べるための、指示のみで構成された
軽量な Agent Skill です。一次資料を読み、裏付けのある主張と未確認の手掛かりを区別し、
重要な違いを簡潔に示してから、元の許可された作業を続けます。

**1.0.0 · MIT · 検証済み範囲：Codex**

## インストール

Skills CLI 1.7.4 は Node.js 22.20 以降と npm を必要とします。host 側に資料の読み取りと、ライブ調査には検索機能が必要です。
同名の Skill が存在しないプロジェクトで実行します。

```sh
npx skills@1.7.4 add orange-clockwork/prior-scout --skill prior-scout -a codex --copy -y
```

版を固定する場合は、取得元を
`https://github.com/orange-clockwork/prior-scout/tree/v1.0.0` に変更します。
内容を確認し、新しい agent session を開始してください。
`npx skills@1.7.4 remove prior-scout -a codex -y` で、このプロジェクトのインストールを削除できます。
ユーザー全体への導入を意図する場合のみ `--global` を指定します。

## 使い方

> $prior-scout を使い、Markdown のファイルリンクと見出しを検査する既存のオープンソースを探してください。
> 一次資料で機能と制約を比較し、その後、私の機能の実装計画を3段階で示してください。

代替案、先行事例、関連研究の明示的な依頼や、外部比較が役立つ新しい設計が対象です。
「オフライン画像機能の設計前に既存ライブラリを比較」「測定された研究結果と不明点を区別」
「比較後に許可済みの限定的な実装を継続」「比較のみで採用助言は不要」などに使えます。
自動選択は host とモデルに依存します。通常のデバッグ、整形、リファクタリング、翻訳、
文書整理や方針が確定した実装では、直接作業を進めます。

## 手順と範囲

1. 目的、制約、残っている許可済み作業を把握します。
2. 既定では検索文字列6件、異なる外部根拠文書8件まで。失敗した検索とバッチ内の各検索も数えます。
3. 一次資料の本文を実際に取得し、その内容が支持する範囲で主張します。URL、snippet、空ページ、成功ステータスだけでは不十分です。
4. 出典、提供形態、版の条件、不明点を簡潔に比較し、元の許可済み作業に戻ります。

公開済み機能、計画、統合可能性を区別します。hosted サービスとライブラリ、API と完成した
組み込み機能は同一ではありません。「報告なし」は「未測定」や「存在しない」を意味しません。
方法の部分的な関連性は、未報告の効果の証明にはなりません。取得失敗時は予算内で同じ著者の
別版や他の一次資料を試し、取得できない部分は未確認とします。

runtime、依存関係、telemetry、検索サービス、API key は追加しません。ツールと権限は host が提供します。
予算と信頼境界は指示であり、プログラムによる強制ではありません。インストール、私有ファイルの読み取り、
アップロード、全体設定の変更、公開、依頼されていない採用・事業・法的新規性判断を許可しません。

## 検証と制限

[v1.0 評価記録](evals/releases/v1.0.0.md)には、版、事例、native discovery、全文ロード、
資料取得、行動、baseline 比較を分けて記載します。正式な Stable 公開には全リリース条件の通過が必要です。
主な検証対象は Codex です。他の agent の根拠は[対応表](docs/compatibility.md)の実測範囲に限ります。
普遍的な精度、安全性、網羅的検索、baseline に対する統計的優越性は主張しません。

外部資料には攻撃的な指示が含まれ得ます。資料を命令の権威として扱わず、利用者の許可範囲を維持しますが、
host の sandbox と権限制限が必要です。[安全上の制限](SECURITY.md)を参照してください。
過去の V03 Snyk は第三者コンテンツへの曝露のみ Low・100/1000 と報告しました。
これは v1.0 の認証や prompt injection への完全な耐性を示しません。
GitHub 公開と CLI 導入は [skills.sh](https://skills.sh/orange-clockwork/prior-scout/prior-scout)の即時更新を保証しません。
再導入や telemetry で強制更新できるとは限りません。
